# Python Activity-Based Learning

## Project Description
This project contains 10 Python case studies selected from the Python Activity-Based Learning assignment.

The project demonstrates basic Python programming concepts through practical real-world problems.

## Selected Case Studies

1. Employee Payroll and Deduction Analysis
2. Retail Billing with Multiple Discount Rules
3. Attendance Recovery Computation
4. ATM Transaction Sequence Simulation
5. Student Performance Trend Analysis
6. Examination Seating Generator
7. Password Policy Validation Engine
8. Student Marks Matrix Analysis
9. Tuple-Based Product Catalogue Audit
10. Energy Conservation Analysis

## How to Run

1. Download or clone this repository.
2. Install Python 3.
3. Open the project folder in VS Code.
4. Open the `python_programs` folder.
5. Run any `.py` file.

Example:

```bash
python 04_employee_payroll.py
```
